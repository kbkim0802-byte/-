# 다이소대본 7단 구조

사용자(JUU_PICK)가 정한 고정 구조. 모든 다이소 대본은 이 순서를 따른다.

## 원본 예시 (사용자 작성)

```
다이소 가면
이거 무조건 사오세요
->> 후킹 문장

남편이 처음엔 슬라이딩 서랍을
만들겠다며 사왔는데
활용도가 미쳤더라고요
-> 반전

바구니 밑에 붙여주니
쓱쓱 움직이는 수납장 되고  -> 기능1

세탁기 옆 틈새에
숨은 서랍을 만들수도 있어요 -> 기능 2

근데 진짜 대박은
티슈 바닥에 붙이면
식탁 밑으로 공중부양되서
깔끔하게 숨길 수 있다는 건데 -> 기능3

심지어 ~~도 할 수 있어요 -> 마지막 도약 소구점 1개

무타공이라 전셋집에도
부담 없이 할 수 있어서 너무 좋네요 -> 구매 전환 유도
```

## 단계별 규칙

1. **후킹**: "다이소 가면 이거 무조건 사오세요" 계열. 제품 이름을 말하지 않는다. 첫 2초 안에 끝난다. 화면에도 제품이 바로 보이지 않게 한다.
2. **반전**: 가족이 **원래 용도**로 사 왔다 → "활용도가 미쳤더라고요". 홈딱 채널의 가족 이야기(아내, 장모님) 형식과 같다.
3. **기능 1**: 가장 기본 활용. "~하니 ~되고"로 다음 문장에 바로 이어 붙인다.
4. **기능 2**: 의외의 장소 (틈새, 안쪽, 뒷면).
5. **기능 3**: "근데 진짜 대박은 ~" 가장 놀라운 활용. 채널에서 반응이 좋았던 **공중부양, 숨기기, 틈새** 콘셉트를 우선한다. "~다는 건데"로 끝내 다음 문장으로 끌고 간다.
6. **마지막 도약**: "심지어 ~도 할 수 있어요." 소구점 딱 1개.
7. **구매 전환**: CTA 금지. 구매를 망설이는 이유 하나를 없애는 문장. 후보:
   - 무타공/전셋집 ("구멍 안 뚫어서 전셋집도 부담 없어요")
   - 가격 ("하나에 1,700원이라 서랍 하나에 3,400원")
   - 개수 계산 ("네 개면 딱 두 군데")
   - 쉬움 ("닦고 붙이기만 하면 끝")

## 완성 예시: 무타공 슬라이딩 레일 (165자, 약 24초 → 156자 이하로 줄일 것)

다이소 가면 이거 무조건 사오세요.
남편이 처음엔 슬라이딩 서랍을 만들겠다며 사왔는데
활용도가 미쳤더라고요.
바구니 밑에 붙여주니 쓱쓱 움직이는 수납장 되고
세탁기 옆 틈새에 숨은 서랍을 만들 수도 있어요.
근데 진짜 대박은 티슈 바닥에 붙이면
식탁 밑으로 공중부양돼서 깔끔하게 숨길 수 있다는 건데
심지어 신발장 안쪽 신발도 쓱 꺼낼 수 있어요.
무타공이라 전셋집에도 부담 없이 할 수 있어서 너무 좋네요.
